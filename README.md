# UTM-реестр

Веб-приложение для ведения единого реестра UTM-меток команды.

## Установка и запуск

```bash
npm install
npm start
```

Приложение будет доступно по адресу `http://localhost:3000`.

Порт можно изменить через переменную окружения `PORT`:

```bash
PORT=8080 npm start
```

Данные (реестр меток и пресеты) хранятся в JSON-файлах в папке `data/`
(`data/registry.json`, `data/presets.json`), которая создаётся автоматически
при первом запуске.
