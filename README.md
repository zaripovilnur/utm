# UTM-реестр

Веб-приложение для ведения единого реестра UTM-меток команды.

## Установка и запуск

```bash
npm install
npm start
```

Приложение будет доступно по адресу `http://localhost:3000`.

Порт можно изменить через переменную окружения `PORT`:

```bash
PORT=8080 npm start
```

Данные (реестр меток и пресеты) хранятся в JSON-файлах в папке `data/`
(`data/registry.json`, `data/presets.json`), которая создаётся автоматически
при первом запуске.

## Админ-панель

По адресу `/admin` доступна отдельная панель администратора: экспорт меток
в Excel и их удаление — больше никаких функций там нет.

Вход защищён паролем, который задаётся через переменную окружения
`ADMIN_PASSWORD`:

```bash
ADMIN_PASSWORD=ваш-пароль npm start
```

Если переменная не задана, вход в админ-панель отключён (сервер отвечает
ошибкой при попытке войти). Сессия хранится в httpOnly-cookie и живёт 12 часов.
